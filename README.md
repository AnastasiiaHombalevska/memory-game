# memory-game

[Demo](https://memory-gamejsrs.netlify.app/)

Memory Game is a card-matching game where the player needs to find all 8 matching pairs of cards.

- The game contains 16 cards forming 8 matching pairs.
- Cards are shuffled randomly at the start of each game.
- The game tracks the number of moves, matched pairs, and elapsed time.
- The leaderboard stores the 10 best completed game results using Local Storage.
- The player can start a new game at any time.
- The application is deployed on Netlify: [Memory Game](https://memory-gamejsrs.netlify.app/)

- To run the application locally, clone the repository:
  ```bash
  git clone

- Switch to the memory-game branch:
  ```bash
    git checkout memory-game
